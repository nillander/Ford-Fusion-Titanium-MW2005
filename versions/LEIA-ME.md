# Histórico de versões

A versão final é a V1prime-z10, distribuída em `release/Fusion2018_AWD_MW2005.zip` (única release).

Nesta pasta ficam o histórico e os aprendizados de cada etapa: LEIA-ME, STATUS, prévias, validações e scripts
das versões v1, v2 (Mustang Shelby), v3, vprime, v1prime (variantes a–z10) e dos checkpoints.
Os binários do jogo das versões antigas (GEOMETRY/TEXTURES/SECONDARYLOGO `.BIN`, `.dds`, `.blend`, ZIPs)
foram retirados em 25/09/2026 para deixar só a release final. Os que estavam versionados continuam no
histórico do git: cada checkpoint tem uma tag (`checkpoint-v1prime-d` … `checkpoint-v1prime-z8`), e
`git checkout <tag> -- <caminho>` recupera o arquivo.
